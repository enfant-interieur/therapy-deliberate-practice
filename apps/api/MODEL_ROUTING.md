# Cloud model routing

The cloud evaluator uses GPT-6.1 Sol with `xhigh` reasoning for educational ratings. Original task creation and parsing that designs missing criteria or examples also use Sol. The model does not establish clinical validity; curators review learning content, and learners interpret feedback with supervision.

GPT-6 Luna with `none` reasoning handles bounded batch segmentation and ordinary translation. Any translation containing grading criteria, rubric anchors or therapist interaction responses goes directly to Sol. Conservative clinical-risk terms also select Sol. If Luna identifies ambiguity or clinical meaning, the operation reruns with Sol. A failed required Sol operation fails the translation; the application does not accept the weaker candidate. Translation preserves identifiers, numeric values, array order and language fields. Source metadata remains outside model output.

All language requests use Responses with strict JSON schema, Zod validation, `store: false`, and zero SDK retries. Incomplete responses and refusals cannot become accepted output. Evaluation allows 16,384 output tokens, task generation 24,576, clinical translation 16,384, and routine translation/segmentation 8,192. These caps include reasoning tokens. Sol requests time out after 180 seconds; Luna requests after 60 seconds. Existing batch validation and queue retries are separate and remain bounded by their service policies. Request-helper cancellation accepts an AbortSignal; this does not imply that a persisted queue job can be cancelled by closing a browser screen.

Speech remains a separate modality: `gpt-4o-mini-transcribe` for transcription and `gpt-4o-mini-tts` for synthesized patient speech. Actual evaluation provider/model identity is recorded by the server. Local evaluations retain `local_unverified` trust and are excluded from public comparison.

The [official GPT-6 migration guide](https://developers.openai.com/api/docs/guides/latest-model#gpt-6-astra-update-api-and-model-parameters) specifies reasoning and sampling compatibility. The [Sol model page](https://developers.openai.com/api/docs/models/gpt-6.1-sol) and [Luna model page](https://developers.openai.com/api/docs/models/gpt-6-luna) describe supported endpoints. Current costs depend on [OpenAI pricing](https://developers.openai.com/api/docs/pricing), input size, reasoning/output usage, cache writes and processing region. Model access depends on the connected account.
